Display protocol: both sides show the same spatial region from the actual LR input and PGSR output. LR is bicubic-resized for display; no extra blur or sharpening is applied. Full images are reduced to web resolution. Detail views use matched 512 × 512 output-space crops. Images are stored losslessly.

The idea

Keep pixel evidence in the loop.

VAE compression can discard fine spatial evidence. PGSR extracts pixel features from the LR image before VAE encoding and reuses them at two stages of restoration.

01 / CONDITION

Guide the trajectory

Fuse pixel features with the latent LR condition to guide the diffusion restoration process.

02 / DECODER

Ground the rendering

Inject multi-scale pixel features into the frozen VAE decoder to recover input-aligned detail.
