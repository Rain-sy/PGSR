The idea

Keep the pixels in the picture.

Latent diffusion priors generate convincing images, but VAE compression can weaken fidelity-critical spatial cues. PGSR extracts pixel features from the upsampled LR observation, independently of the pretrained VAE, and reuses them at two stages.

01

Guide the trajectory

Gated residual fusion combines pre-VAE pixel features with the LR latent condition, grounding the restoration trajectory in the observed image.

02

Ground the rendering

Multi-scale Decoder-side Feature Modulation (DFM) injects pixel evidence into the frozen VAE decoder to recover input-aligned detail.

Built on FLUX.1-dev, with an additional sparse-attention variant for more efficient high-resolution restoration. See the paper for experiments and implementation details.
